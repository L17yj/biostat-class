# 生物統計實習 (Biostatistics Lab)

國立臺灣大學 / 相關課程之生物統計實習作業、報告與分析資料庫。

## 專案內容說明
- **資料檔案 (`data/`, `*.sav`, `*.xlsx`, `*.xls`)**：包含實習使用之統計資料集（SPSS 格式與 Excel 格式）。
- **分析報告與作業 (`*.doc`, `*.docx`, `*.pdf`)**：各週次的實習報告、ANOVA、獨立樣本 t 檢定、卡方檢定與存活分析等。
- **分析腳本 (`*.py`)**：統計圖表產製與數據分析自動化腳本。

## 主要分析主題
1. 獨立樣本 t 檢定 (Independent t-test)
2. 變異數分析 (ANOVA)
3. 無母數統計檢定 (Mann-Whitney U test, Kruskal-Wallis test)
4. 相對危險度與勝算比分析 (RR / OR Analysis)
5. 存活分析 (Survival Analysis)
